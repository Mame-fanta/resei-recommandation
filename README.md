# RESEI — Prototype de recommandation IA

Projet de mémoire de Mame Fanta GOUMBALA, OZAMBA / NEXA Digital School.

## Exécution locale

```bash
python -m pip install -r requirements.txt
python -m streamlit run app_resei_finale.py
```

## Déploiement Streamlit Community Cloud

1. Créer un dépôt GitHub, puis importer les fichiers à la racine.
2. Sur https://share.streamlit.io, sélectionner **Create app** et connecter GitHub.
3. Choisir la branche `main` et le fichier principal `app_resei_finale.py`.
4. Cliquer sur **Deploy**, puis tester le lien public obtenu.

**Important :** les données d'entraînement sont expérimentales/simulées. Le back-office est une démonstration sans authentification et les feedbacks ne sont pas persistés. Ne pas saisir de données personnelles réelles.
